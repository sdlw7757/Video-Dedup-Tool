## 简介

这是一个基于 Python 和 FFmpeg 的视频去重工具，通过修改视频的视觉特征和文件特征来实现视频去重，避免平台的重复内容检测。本工具已集成所有必要组件，可直接运行。

## 功能特性

1. **水平镜像** - 对视频进行水平翻转
2. **RGB偏移** - 对视频的RGB通道进行轻微偏移
3. **时间跳跃** - 让视频中的帧进行周期性的变速波动（肉眼看不到）
4. **修改MD5值** - 通过重新编码和添加元数据修改文件MD5值
5. **蒙版倒置** - 通过调整视频透明度来创建视觉变化效果
6. **视频抽针** - 通过抽取特定帧来创建视频变化（保留原时间戳，不补帧）
7. **批量处理** - 文件列表支持批量添加文件/文件夹，逐项显示处理状态
8. **参数随机化** - 为每个文件独立在安全区间随机取值，避免批量输出彼此相似
9. **音频基础处理** - 仅做音量微调与重采样，**不改变音调与播放速度**

## FFmpeg 组件说明（ffmpeg.exe / ffprobe.exe）

本工具依赖以下两个 FFmpeg 可执行文件，**必须**位于 `ffmpeg-8.0/bin/` 目录内：

| 文件 | 路径 | 用途 |
| --- | --- | --- |
| `ffmpeg.exe` | `ffmpeg-8.0/bin/ffmpeg.exe` | 视频去重处理（水平镜像、RGB 偏移、时间跳跃、蒙版倒置、视频抽针、重新编码、嵌入缩略图） |
| `ffprobe.exe` | `ffmpeg-8.0/bin/ffprobe.exe` | 读取视频信息（时长、帧率、是否含音轨），用于显示处理进度与参数取值 |

程序通过项目内的相对路径调用这两个文件，无需配置环境变量，也无需单独安装 FFmpeg。

> ⚠️ **重要**：这两个文件必须是**真实的 Windows 可执行程序**（每个约 80 MB）。
> 如果它们的体积只有约 130 字节，说明是 Git LFS 占位文件（直接下载 GitHub 的 zip 包时会出现这种情况），
> 程序无法调用它，点击"开始处理"会失败。请执行 `git lfs pull` 拉取真实文件，
> 或手动将其替换为真实的 ffmpeg/ffprobe 二进制文件。

## 使用方法

### 方法一：使用启动脚本（推荐）

1. 双击运行 ``start.bat`` 文件
2. 通过“添加文件”/“添加文件夹”把要处理的视频加入文件列表（支持批量）
3. 勾选需要的去重功能，按需开启“参数随机化”“音频基础处理”
4. 点击“开始处理”按钮（处理中可点击“取消”）
5. 处理完成后，输出文件保存在**源文件同目录**下，命名为 `原名_dedup.扩展名`；若已存在则自动追加序号，不会覆盖原文件

### 方法二：直接运行Python文件

在命令行中执行：
```bash
python video_dedup_tool.py
```
或者
```bash
python\python.exe video_dedup_tool.py
```

## 功能详解

### 时间跳跃
让视频中的帧进行周期性的变速波动（肉眼看不到），通过使用minterpolate滤镜创建微妙的时间波动效果，在保持视频总时长不变的情况下，创建微妙的帧速率变化，肉眼几乎察觉不到但能有效避免重复检测。

### RGB偏移
让视频 RGB 颜色通道按设置偏移，达到换色目的。通过对RGB通道进行轻微的空间偏移来产生视觉差异。

### 水平镜像
让视频进行左右镜像翻转，改变视频的视觉内容但保持内容完整性。

### 修改MD5值
通过重新编码视频并添加随机元数据，规避平台重复检测。确保输出文件的MD5值与原文件不同。

### 蒙版倒置
通过调整视频透明度来创建视觉变化效果，可设置透明度值（0-1），默认值为0.03。

### 视频抽针
通过抽取特定帧来创建视频变化，可设置抽针间隔，默认每隔5帧抽取1帧，也支持随机间隔模式。输出使用变帧率（`-fps_mode vfr`）保留原时间戳，确保真正丢帧且视频总时长不变。

### 参数随机化
开启后，每个文件独立在安全区间随机取值（CRF、GOP、B帧、RGB偏移、蒙版值、抽针间隔、音频音量/采样率等），避免批量输出彼此相似；关闭时使用固定默认值。

### 音频基础处理
仅做**音量微调**（`volume`）与**重采样**（`aresample`）两项处理，**不会改变音调，也不会改变播放速度**。为避免歧义，程序不使用 `asetrate`/`atempo` 等会变速变调的滤镜。无音轨的文件会自动跳过音频处理。

## 注意事项

1. 支持的视频格式：MP4、AVI、MKV、MOV、WMV、FLV、WEBM等主流格式
2. 处理时间取决于视频大小和选择的功能数量
3. 处理过程会占用一定系统资源，请耐心等待
4. 请确保有足够的磁盘空间存储处理后的视频文件
5. 本工具已集成所有必要组件，无需额外安装
6. 如果启动失败，请检查杀毒软件是否阻止了程序运行
7. 处理完成后会为 MP4/MOV/M4V/MKV 输出嵌入一张缩略图（内嵌封面），便于在文件管理器中预览

## 开发说明

### 主要文件

- `video_dedup_tool.py` - 主程序文件，包含GUI界面和处理逻辑
- `start.bat` - Windows启动脚本（优先使用项目自带 Python，缺失时回退到系统 Python 或 py 启动器）
- `ffmpeg-8.0/bin/ffmpeg.exe` - FFmpeg主程序
- `python/python.exe` - Python解释器

### 核心处理流程

1. 用户选择视频文件和功能选项
2. 根据选择构建FFmpeg命令
3. 调用FFmpeg执行视频处理
4. 实时监控处理进度
5. 生成处理后的视频文件

### FFmpeg命令说明

程序会根据用户选择的功能构建相应的FFmpeg命令：

- `-vf` 参数用于视频滤镜处理
- `-af` 参数用于音频基础处理（`volume` + `aresample`，不变调）
- `-map_metadata -1` / `-map_chapters -1` 清除原有元数据与章节，再用 `-metadata` 写入新的元数据
- `-c:v libx264` 用于视频重新编码，并附加 `-profile:v high -pix_fmt yuv420p -g/-bf` 等编码参数
- `-fps_mode vfr` 在抽针时保留原时间戳

## 常见问题

### 启动失败
1. 确保所有文件都在同一目录下
2. 确保Windows系统完整性
3. 检查杀毒软件是否阻止了程序运行

### 处理失败
1. 检查视频文件是否损坏
2. 确保磁盘有足够空间
3. 关闭可能占用视频文件的其他程序

### 处理时间过长
1. 视频文件较大时处理时间会相应增加
2. 选择的功能越多处理时间越长
3. 可以尝试降低视频质量设置来加快处理速度
